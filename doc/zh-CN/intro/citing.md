# 如何引用 CICE 代码

每个单独发布的版本都有自己的数字对象标识符（Digital Object Identifier，DOI）。例如，CICE v6.1.2 的 DOI 是 `10.5281/zenodo.3888653`。这一系列的所有版本（例如 CICE6）都可以使用 DOI [`10.5281/zenodo.1205674`](https://zenodo.org/record/1205674) 引用。该 DOI 代表所有 v6 版本，并且始终解析到最新版本。更多信息请查看 DOI 指向的 Zenodo 页面。

使用 CICE 时，请引用所使用或修改的代码版本号。

如果使用 CICE Consortium 仓库 `main` 分支中尚未编入编号版本的修改，除引用最近的版本号外，还可以引用下载时的提交哈希（hash）；在本地克隆仓库中执行 `git log` 可查到该值。自己的修改提交到仓库分支后，也可以引用相应哈希。

也请将使用 CICE 的情况和相关出版物告知 CICE Consortium。
